External Device APIs

このブラウザから外部デバイスへ、どのWeb APIでアクセスできるかを診断します。外部機器が必要なAPIは「API対応」と「実機で動いた」を分けて表示します。

⬅ 本体センサーに戻る
一部の外部デバイスAPIは、このブラウザで非対応です。非対応表示も診断結果です。

よくある質問 (FAQ)

Q. 非対応のAPIが多い

A. 正常です。Web Bluetooth / WebUSB / Web Serial / Web NFC / WebHID / Gamepad / Web MIDIなどはブラウザやOSによって対応状況が大きく異なります。この差を見ること自体がこのページの目的です。

Q. 「API対応」なら実際に使える？

A. 外部デバイスAPIは相手となる機器が必要です。そのためAPIの入口があることと、実機との接続・通信が成功することを分けて扱います。対応機器がある場合は可能な範囲で実接続まで試します。

Q. Bluetoothで心当たりのないデバイスが表示される

A. BLE対応機器が周囲に多数ある場合があります。ブラウザはユーザーが選択したデバイスだけにアクセスを許可します。

Q. Web NFCでSuicaやマイナンバーカードが読めない

A. Web NFCはNDEF形式を対象とします。SuicaのFeliCaやマイナンバーカードのような低レベルの専用通信をWeb NFCから直接読むことはできません。

Q. WebUSBは何が分かる？

A. 現在の実装ではデバイス選択と識別情報の確認が中心です。実際の転送には対象機器固有のconfiguration / interface / endpoint仕様が必要です。
